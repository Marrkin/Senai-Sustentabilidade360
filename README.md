# Sustentabilidade360

Site do projeto de Extensão 2 do curso superior de Mecatrônica do SENAI. Três cenários interativos apresentam possíveis destinos do concreto que sobra em fábricas de pré-moldados e obras.

## Desenvolvimento

Com Node.js 22, execute `npm ci` e `npm run dev`. O site fica disponível em `http://localhost:3000`.

## Hospedagem

Importe este repositório na Vercel usando o preset Next.js. O projeto usa `npm run build` e dispensa variáveis de ambiente. Para conferir a versão de produção localmente, execute `npm run build` e depois `npm start`.
